# Análisis de Ventas de Tiendas

## Descripción del proyecto
Este proyecto consiste en un análisis de datos de ventas de cuatro tiendas con el objetivo de ayudar al Sr. Juan a decidir a cuál tienda le conviene vender. Para ello, se analizaron diferentes factores como los ingresos totales, las categorías de productos más vendidas, las calificaciones de los clientes, los productos más y menos vendidos y el costo promedio de envío.

El análisis fue realizado utilizando Python en Google Colab, principalmente con las bibliotecas **Pandas** y **Matplotlib** para el procesamiento de datos y la generación de gráficos.

## Objetivo
Comparar el desempeño de las cuatro tiendas a partir de diferentes indicadores para determinar cuál es la mejor opción para que el Sr. Juan venda sus productos.

## Análisis realizados
Durante el proyecto se realizaron los siguientes análisis:

- **Ingresos totales por tienda**
- **Ventas por categoría de producto**
- **Calificación promedio de los clientes por tienda**
- **Productos más y menos vendidos**
- **Costo promedio de envío por tienda**
- **Análisis opcional de coordenadas geográficas de ventas**

## Herramientas utilizadas

- Python  
- Pandas  
- Matplotlib  
- Google Colab  

## Resultados

Después de analizar los datos y generar diferentes visualizaciones, se encontró que:

- **La Tienda 1 tiene los ingresos más altos.**
- **La Tienda 3 tiene la mejor calificación promedio de los clientes.**
- **La categoría más vendida en todas las tiendas es Muebles.**
- **La Tienda 4 tiene el costo de envío promedio más bajo.**

Tomando en cuenta todos los factores analizados, se recomienda que **el Sr. Juan venda a la Tienda 1**, ya que presenta el mejor desempeño general en términos de ingresos.
